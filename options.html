Bound settings

On-device by default. Optional ChatGPT for harder snippets.

How analysis runs

Bound always ships with an on-device checker: nested loops, recursion, sorts, binary search, hash maps, and common contest patterns. No account is required. If you turn on OpenAI, the code Bound extracts is sent to that API so a model can name best / average / worst bounds.

Hook up ChatGPT (OpenAI)

  1. Create an API key at platform.openai.com/api-keys. This is billed to your OpenAI account, not through Bound.
  2. Choose OpenAI / ChatGPT as the engine below.
  3. Paste the key. Bound stores it in chrome.storage.local on this machine only — it is not uploaded anywhere else.
  4. Keep the model at gpt-4o-mini unless you want a larger model.
  5. Save, then click the Bound icon (or press Alt+Shift+T) on a page with code.

Hook up another OpenAI-compatible server

Anything that implements POST /chat/completions works: Azure OpenAI, a proxy, or a local server such as Ollama at http://localhost:11434/v1 with model llama3.1. Chrome will ask you to allow access to that host the first time you save.
